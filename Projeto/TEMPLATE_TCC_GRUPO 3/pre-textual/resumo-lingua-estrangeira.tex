\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
This Course Completion Project presents the development of \textit{SyncCarreira}, a \textit{Software as a Service} (SaaS) web platform designed to support the vocational guidance process in educational institutions. The project starts from the observation that vocational guidance conducted manually makes it difficult for guidance professionals to continuously follow large classes and to identify the students who need assistance. Based on requirements defined together with a partner psychologist, the platform organizes the student's journey into sequential trails, with a mandatory written synthesis at the end of each stage, and presents, at the end of the journey, a range of fields and careers calculated from the declared interests and the answers, without diagnostic character. For the guidance professional, the system provides a class monitoring dashboard that preserves the confidentiality of the answers, automatic flagging of students who remain undecided, session scheduling integrated with Google Calendar, feedback delivery, curation of external information sources and report generation, while the Administrator manages multiple institutions with data isolation. The solution was built with a REST API in Java with Spring Boot, protected by JWT tokens, a React web application and a MySQL database, and was deployed on Amazon Web Services. The server code is verified by 470 automated test methods, with 89.3\% coverage and approval in the static analysis quality gate. As a result, eight of the ten specific objectives were fully met and two were partially met, with an estimated operating cost of approximately R\$ 181.60 per month. The identified limitations, such as the lack of encryption of sensitive data at rest, guide future work.
