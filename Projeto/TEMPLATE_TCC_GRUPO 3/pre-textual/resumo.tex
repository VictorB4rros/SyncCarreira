\begin{resumo}
Este Projeto de Conclusão de Curso apresenta o desenvolvimento do \textit{SyncCarreira}, uma plataforma \textit{web} no modelo \textit{Software as a Service} (SaaS) destinada a apoiar o processo de orientação vocacional em instituições de ensino. O projeto parte da constatação de que o acompanhamento vocacional conduzido de forma manual dificulta ao profissional de orientação acompanhar continuamente turmas numerosas e identificar os estudantes que necessitam de atendimento. Com base em requisitos definidos em conjunto com uma psicóloga parceira, a plataforma organiza a jornada do aluno em trilhas sequenciais, com registro obrigatório de uma síntese ao final de cada etapa, e apresenta, ao término da jornada, um leque de áreas e carreiras calculado a partir dos interesses declarados e das respostas, sem caráter de diagnóstico. Ao profissional de orientação, o sistema oferece um painel de acompanhamento por turma que preserva o sigilo das respostas, a sinalização automática dos alunos que permanecem em dúvida, o agendamento de sessões integrado ao Google Agenda, o envio de \textit{feedback}, a curadoria de fontes externas de informação e a emissão de relatórios, enquanto o Administrador gerencia múltiplas instituições com isolamento de dados. A solução foi construída com uma API REST em Java com Spring Boot, protegida por \textit{tokens} JWT, uma aplicação \textit{web} em React e banco de dados MySQL, e foi implantada na Amazon Web Services. O código do servidor é verificado por 470 métodos de teste automatizados, com cobertura de 89,3\% e aprovação no critério de qualidade da análise estática. Como resultado, oito dos dez objetivos específicos foram plenamente atendidos e dois parcialmente, com custo estimado de operação de aproximadamente R\$ 181,60 por mês. As limitações identificadas, como a ausência de criptografia dos dados sensíveis em repouso, orientam os trabalhos futuros.

\end{resumo}
