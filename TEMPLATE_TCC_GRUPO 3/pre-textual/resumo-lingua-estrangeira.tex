\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
    This study describes the development of SyncCarreira, a \textit{Software as a Service} (\textit{SaaS}) platform aimed at automating and optimizing vocational guidance processes in educational institutions. Motivated by the inefficiency of manual methods, which overload school psychologists and hinder longitudinal student tracking, the solution centralizes data, automates test scoring, and provides analytical dashboards for classroom management. Using technologies such as React for the front-end, Java with Spring Boot for the back-end, and MySQL for persistence, the application was built on a layered architecture and Scrum agile methodologies. Expected results include reduced bureaucracy, increased student engagement, and qualified technical support for vocational decision-making, while ensuring compliance with the General Data Protection Law (LGPD).

\vspace{\onelineskip}
\noindent
\textbf{Keywords}: Vocational Guidance. Automation. SaaS. Educational Technology. Data Management.
\end{otherlanguage*}
\end{resumo}
