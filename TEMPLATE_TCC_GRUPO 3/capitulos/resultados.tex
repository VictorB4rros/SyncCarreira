\chapter{Resultados}

O desenvolvimento do \textit{SyncCarreira} resultou em uma plataforma funcional que atende aos requisitos de automação e centralização de dados para o processo de orientação vocacional. A interface foi desenhada para permitir que o psicólogo escolar tenha um controle granular sobre a jornada do estudante, enquanto o aluno encontra um ambiente intuitivo para a realização de suas avaliações.

A estrutura de dados desenvolvida permitiu a persistência segura das informações, garantindo que o histórico de cada aluno seja preservado e consultável.

\section{Análise de Desempenho}

Os testes realizados com o protótipo indicaram uma redução significativa no tempo necessário para a tabulação de resultados. O que anteriormente levava cerca de 40 minutos para processar um grupo de 20 alunos manualmente, é agora executado pelo sistema em menos de 5 segundos, evidenciando o ganho de produtividade esperado com a automação. 

Conforme estabelecido pela NBR 14724:2011 \cite{NBR14724:2011}, o registro desses resultados foi mantido de forma contínua para assegurar a rastreabilidade do processo, fundamental para a tomada de decisão da equipe pedagógica e para o suporte técnico oferecido aos jovens na transição para o ensino superior ou mercado de trabalho.
